Lesson 1

Introduction to Programming

Understand what programming is, how programs work and why programming is important in technology.

What you will learn

In this lesson you will learn the basic idea of programming and how instructions are given to a computer.

  • Understand what programming means.
  • Understand how computers execute instructions.
  • Identify common programming languages.
  • Understand the relationship between algorithms and programs.

Lesson Notes

Programming is the process of creating instructions that a computer can execute to perform a particular task.

A programming language provides a structured way for humans to communicate instructions to computers.

Examples include C++, Python, JavaScript, Java and many others.
